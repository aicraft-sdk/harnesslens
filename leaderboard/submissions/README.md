# submissions/

Each file in this directory is one self-reported `harnesslens` score for a
participating repo, named `<repoId-with-slashes-replaced-by-dashes>.json` (e.g.
`ai-craft-harness-audit.json` for `repoId: "ai-craft/harness-audit"`). Submissions are
added and updated via pull request — see the submission schema, the PR-based trust model,
and the copy-pasteable external Action snippet in
[`../README.md`](../README.md#submission-schema).
